Current project in development

Appointed

  • Godot
  • GDScript
  • Game design
  • Level design
  • Narrative design

A first-person game set in Paládia, a technocratic meritocracy. The player works mundane jobs that the state broadcasts as critical service: mining, farming, cleaning, paperwork. The working equipment is both tool and weapon.

The story follows a four-part Kishōtenketsu structure with a strong satirical undertone. Tension builds by accumulation, and a late turn reframes everything before it. A questionnaire after each level records the player's answers and decides which ending they reach.

Commercial release planned on Steam via Manifest Games GbR.

  • Systems design

A narrative isometric RPG about a sugar refinery during the industrial age of a fictional universe. Where workplace simulations usually make you the boss, here you are one worker among many, and progress is collective rather than personal.

Written as a fifteen-page high concept for a funding application: core loop, design pillars, cast, audience, age rating, competitive analysis against Disco Elysium, Papers Please, Suzerain, Frostpunk and Citizen Sleeper, and a development plan.

B.Sc. thesis · 2024

Generation and adaption of quest-based virtual environments

  • Unity
  • C#
  • Python
  • Procedural generation
  • LLM integration

Procedural generation of game environments shaped by quest structure. An LLM produces a structured description of the intended environment: regions, points of interest, NPCs and narrative framing. The generator parses it and builds a terrain to match, partitioning the map into regions with a Voronoi diagram, generating a heightmap and then placing objects by rule.

Unity engine tool · 2023

detec2d

  • Unity
  • C#
  • Game AI
  • Editor tooling

A 2D detection system for Unity in which agents perceive the player through vision and sound. Agents react through an interface instead of direct references, so any object can become a detection target, and detection events go through an event manager rather than agents polling each other every frame.

Custom inspectors make the vision cone and sound radius editable and visible in the editor, so a designer can tune the system without touching code.

Homelab

Home Infrastructure

  • Ubuntu Server
  • Docker Compose
  • Ansible
  • Tailscale
  • Infrastructure as code

A self-hosted server running Nextcloud with Collabora, Navidrome, Syncthing, Pi-hole as the network's DNS and a Prometheus and Grafana monitoring stack, with CrowdSec as the intrusion prevention layer.

Managed entirely as code: every compose file and service unit lives in an Ansible repository on my workstation and is deployed from there, so the server holds no configuration that is not reproducible. Every web interface binds only to the Tailscale interface; the one port open to the local network is Pi-hole's DNS, which the devices there need.
